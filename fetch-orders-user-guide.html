Fetch Orders 用户操作说明

用于下载上游订单 Excel 文件，下载完成后可继续做订单对账。

先看这三件事

重要提醒：loginConf.ini 里面有账号、密码、apikey、token 等敏感信息。请自己保管，不要发给任何人，不要截图外发，也不要上传到任何公共位置。
  • 第一次使用前，必须先准备 loginConf.ini。
  • api_key 已经默认填好；你只需要填写 username、password、institution_id。
  • 下载后的 Excel 会放到 workspace/diffOrders 文件夹。

第一步：复制配置文件

1

找到模板文件

在工具文件夹里找到：

loginConf.example.ini

2

复制一份

复制这个文件，得到一个副本。

3

改名为 loginConf.ini

把复制出来的文件改名为：

loginConf.ini

注意：名字必须完全一样，大小写也尽量保持一致。

第二步：填写登录信息

用文本编辑器打开 loginConf.ini，找到这一段：

[upstream_server_login]
api_key = 已经默认填好，不要删除
username =
password =
institution_id =

其中 api_key 已经在模板里默认填好，一般不要修改。请把下面三项的等号后面填上真实值。

字段 怎么填
api_key 模板已默认填好。除非维护人员要求，否则不要修改、不要删除。
username 填写上游后台登录用户名。
password 填写上游后台登录密码。
institution_id 填写上游后台登录所需机构 ID。
其他字段：ip_address、session_id、transition_id 如果没人特别要求，可以先留空。

第三步：运行下载工具

如果你使用的是打包后的工具

打开 dist/AutoExcelKit 文件夹，确认里面有：

  • fetch-orders
  • config.ini
  • loginConf.ini

然后运行 fetch-orders。

如果你在项目根目录运行

确认项目根目录里有 loginConf.ini，然后运行拉取订单脚本。

如果你不懂命令行，使用打包后的 dist/AutoExcelKit/fetch-orders 更简单。

第四步：按提示选择

程序登录成功后，会出现这个问题：

是否需要生成最新的 Excel？输入 y 生成，直接回车或输入 n 按日期下载已生成文件：

不生成新的 Excel，只下载已经生成好的 Excel

直接按回车，或者输入 n。

程序会继续询问需要下载哪一天的数据，直接回车默认前一天；然后筛选该日期的文件，下载列表中的第一个可下载 Excel。

需要后台重新生成一份 Excel

输入 y，然后按回车。

接着程序会让你输入日期：

请输入拉取订单日期，直接回车默认前一天 YYYY-MM-DD：

可以输入：

  • 2026-06-28
  • 0628
  • 06-28
  • 06/28

如果直接回车，就使用提示里的默认日期。

第五步：查看下载结果

成功后，会看到类似提示：

Excel 下载完成：.../workspace/diffOrders/TranDetailReport_87382398_20260629141406.1587508.xlsx

下载好的 Excel 在这个文件夹：

workspace/diffOrders

文件名一般长这样：

TranDetailReport_87382398_20260629141406.1587508.xlsx

常见问题

1. 登录成功了，但后面查询报 401

通常是默认 api_key 被误删、改坏，或者当前运行目录下的 loginConf.ini 不是你真正填写的那份。

请检查：

  • api_key 是否还保留模板里的默认值
  • username 是否正确
  • password 是否正确
  • institution_id 是否正确
  • 你运行工具的那个文件夹里，是否真的有填好内容的 loginConf.ini

2. 我不想生成新的 Excel

在“是否需要生成最新的 Excel？”那里直接按回车，或者输入 n。

3. 找不到下载后的文件

看程序最后一行的“Excel 下载完成”路径。默认位置是：

workspace/diffOrders

4. 换了账号后还是不正常

打开 loginConf.ini，清空 [upstream_server_session] 下面旧的 token 等内容，然后重新运行。
